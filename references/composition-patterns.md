# Composition Patterns

每張圖只選一個主要 pattern。

## 1. Hero Race / Burden Comparison

適合：新方法勝過舊方法、速度／成本／負擔差異。

- 上方置中標題。
- 中下方兩條可比較路徑。
- 用負擔、卡片堆、車輛、道路或終點表達差距。
- 右側放 2–3 個短結果卡。

## 2. Hybrid Stack Tableau

適合：3:1、主次模組、混合架構。

- 用可數的紙雕模組堆疊或車載。
- 顏色直接表達模組類型。
- 標註卡只命名數量、功能與結果。

## 3. Gate / Mechanism Tableau

適合：寫入、保留、遺忘、篩選、路由、分配。

- 左側舊方法或粗閘門。
- 中間明確轉換。
- 右側 2–4 個細分機制與最終容器。
- 可不使用人物。

## 4. Growing Burden Comparison

適合：KV cache、成本、延遲、資料量隨規模增加。

- 上下或左右兩條路徑。
- 相同里程標記。
- 一條維持穩定，另一條逐步堆高或變重。
- 右側結果卡與必要但書。

## 5. Process Journey

適合：原料到結果、研究到部署、內容到轉化。

- 一條連續道路或紙帶穿過 3–4 個站點。
- 每個站點只有一個動作。
- 結尾用旗幟、出口、完成物或結果卡。

## 6. Before / After Landscape

適合：混亂／有序、粗粒度／細粒度、舊／新。

- 兩個自然場景，由一個轉化動作連接。
- 不寫大字 BEFORE / AFTER。

## 7. Timeline Route

適合：歷史演進、產品迭代、規模成長。

- 一條彎曲路徑與少量里程碑。
- 不做四格投影片。

## 反重複規則

- Hero 已表達的主架構，不再用第二張完整架構圖重複。
- 同一篇文章同一 pattern 最多使用兩次。
- 文內圖要保留同風格，但更換主物件與視覺動作。
