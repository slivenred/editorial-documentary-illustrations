# Explainer Composition Patterns

參考清楚的產品與媒體圖示：先給讀者一句結論，再用一個主視覺與少量解釋卡完成閱讀。版型服務內容，不追求複雜藝術構圖。

## 共通骨架

- Header：eyebrow、headline、subheadline。
- Visual：VOX-inspired 羊皮紙剪紙主場景。
- Explainers：2–4 張短卡，具有固定順序。
- 文字面積通常不超過 30–35%。
- 一張圖只回答一個問題。

## 1. Hero Explainer

適合：精選圖片、整篇主張、重要新產品或研究。

- Header 約 22%。
- 中央主視覺約 52–58%。
- 下方 3 張卡約 20–24%。
- 不把所有章節塞入 hero；只留一個主張和三個支點。

## 2. Mechanism Focus

適合：演算法、內部機制、RAG、記憶、推薦。

- Header 在上。
- 主機制位於左側約 60%。
- 右側垂直排列 2–4 張卡。
- 卡片對應可見元件，但不使用交叉 callout 線。

## 3. Process Strip

適合：3–5 個步驟的流程。

- 中間以一條剪紙路徑串起階段。
- 下方卡片依左到右順序排列。
- 每張卡只寫階段名稱和一句作用。

## 4. Comparison Split

適合：舊／新、A／B、成本／品質、滿注意力／混合注意力。

- 中央左右對比，條件盡量一致。
- 下方兩張主要卡對應左右兩側。
- 可加第三張居中的總結卡。
- 不使用密集長條圖、圖例與多層括號。

## 5. Timeline Route

適合：歷史、產品演進、從小到大。

- 一條彎曲路徑穿過 3–4 個場景。
- 下方卡片對應階段。
- 不做硬切四格簡報。

## 6. Result Board

適合：研究結果、指標、決策建議。

- 中央保留一個結果場景或簡單比較。
- 下方 2–4 張卡突出關鍵數字與條件。
- 數字必須保留單位與限制，不只畫獎盃或上升箭頭。

## 避免

- 散落在畫面四周的十幾張標籤。
- 大量交叉 callout 線。
- 一張圖同時使用流程、時間軸、比較與生態全景。
- 把技術文章畫成精密論文架構圖。
- 泛用機器人、腦、伺服器城市、齒輪工廠。
