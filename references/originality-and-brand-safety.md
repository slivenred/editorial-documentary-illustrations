# Originality and Brand Safety

## 對外名稱

公開 repo、商業服務或客戶交付建議使用：

- Editorial Documentary Illustrations
- Documentary Cutout Article Illustrations
- 紀錄片剪紙文章配圖

不要把產品命名成「Official Vox Skill」「Vox Generator」或其他容易造成官方合作誤解的名稱。

## 使用者仍可用 VOX 關鍵字觸發

Skill 的 description 可以包含：

- VOX-inspired
- VOX 風格
- modern explainer journalism
- historical documentary cutout
- parchment map animation

但生成 prompt 的核心必須是具體視覺 DNA，不可只依賴品牌名稱。

## 原創構圖與標註

允許：

- 羊皮紙。
- 剪紙人物。
- 地圖路徑。
- 現代解說新聞式視覺敘事。
- time-lapse 的動態暗示。
- 土色系、柔和陰影、俯視鏡頭。
- 由文章上下文重新撰寫的短句認知標註。
- 原創紙片標籤、手繪連線與色彩語意。

不允許：

- 複製某支影片的鏡位、人物排列與物件位置。
- 使用 Vox logo、黃色標題卡、特定品牌字體或版型。
- 模仿某一張既有圖的完整標註位置與文字層級。
- 把既有畫面稍微換色就交付。
- 宣稱是 Vox Media 官方或合作產品。
- 使用使用者未授權的照片、角色或品牌素材。
- 在 repository 內附帶第三方字型檔。

## 抽象語法，不是特定作品

每張圖都從當前文章重新建立：

1. 認知錨點。
2. 物理動作。
3. 場景空間。
4. 主體。
5. 規模或時間變化。
6. recurring motif。
7. 一句核心判斷。
8. 指向實際物件的短標註。

即使兩篇文章都談「傳播」，也不能固定畫同一條路線、同一群人或同一組 labels。

## 原始專案歸屬

本 Skill 的多步驟架構參考 Ian 的 `ian-xiaohei-illustrations`：

- 文章認知錨點。
- shot list。
- 單張生成。
- 短句、少量、服務理解的文內標註原則。
- 風格參考檔。
- QA 與迭代。

本套件已重新撰寫視覺系統、角色系統、構圖、annotation renderer、manifest、prompt compiler 與驗收流程，不包含小黑 IP、原提示詞、字型或原範例圖片。保留 attribution 與 MIT license notice。
