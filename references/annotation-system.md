# Integrated Text System

## 主流程

最終圖預設直接包含文字。文字不是後加的散落貼紙，而是與羊皮紙、邊框、場景和標註卡共同構成完整畫面。

## 文字階層

1. `eyebrow`：0–1 個，產品名、主題名或短分類。
2. `headline`：一句核心判斷，最大視覺層級。
3. `subheadline`：一句原因、條件或結果補充。
4. `labels`：2–4 個，命名場景中的重要物件或數據。
5. `bottom_takeaway`：一句總結，可選。
6. `caveat`：一句限制，可選。

## 直接生圖文字規則

- 提示詞逐項列出精確字串。
- 明寫 `Render these exact strings and no other text`。
- 品牌、模型、版本、數字與單位保留原文。
- 中文採文章地區用詞；`zh-TW` 使用台灣繁體中文。
- 不讓 headline 超過三行。
- 不讓 labels 超過四個。

## 修正策略

1. 只有單一錯字：用圖片編輯替換單一字串。
2. 多個文字錯誤但構圖正確：保留場景，重新渲染文字層或局部重做。
3. 文字擁擠：先減字，不先縮到不可讀。
4. 文字遮住主體：移動標註卡或縮短文字。
5. 場景不相關：重生整張，文字修正無法補救。

## 版面規則

- 標題位於上方置中。
- 標註卡靠近目標物，但不壓住目標物。
- 引線保持短、少、無交叉。
- Bottom takeaway 位於底部安全區。
- Caveat 放在角落的獨立紙片，不與主結論競爭。
