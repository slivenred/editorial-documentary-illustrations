# Character and Object System

## Semantic priority

People are optional. They may appear only when people are real actors in the article or when a controlled metaphor explicitly maps their role. For technical research, model components, layers, token streams, state cells, memory trails, comparison tracks, and scientific artifacts should usually carry the narrative. Do not add office workers around a generic machine to make an algorithm look active.

## 人物目標

人物是敘事單位，不是肖像。要能看懂誰在做什麼，但不需要精細五官、手指、肌肉或寫實服裝。

## 三級人物

### Primary actor

- 1–3 人。
- 可辨認基本職業或角色。
- 頭部為簡化紙片形狀。
- 眼鼻嘴極簡或省略。
- 手臂為簡單剪紙條；手掌以圓角紙片或袖口暗示。
- 不做手部近景。
- 動作輪廓要清楚，例如翻炒、搬運、排隊、搭建、交付。

### Secondary actors

- 3–8 人。
- 使用 2–4 種固定姿勢與服裝變體。
- 臉部只保留方向，不畫細節。
- 可用背影、側影、坐姿與走路姿勢。
- 不讓每個人都做不同複雜動作。

### Crowd clusters

- 8 人以上時，不逐一描述每個人。
- 使用 2–5 組剪紙群眾 cluster。
- 每組由重疊半身、頭部、桌椅或隊伍形狀構成。
- 前景可有 2–3 個較清楚角色，其餘簡化。
- 用路徑、隊伍長度、桌子數、盤子數或建築密度表示「rame／熱鬧」。

## 動作語法

優先：

- 走向、匯聚、排隊、交付、端盤、搬運、攪拌、組裝、搭建、打開、展開、交換、坐下、散開。
- 以身體方向、腳步路徑、物件軌跡表達，不依賴手指細節。
- 同一角色需要時間感時，可重複 2–3 個半透明或淡色位置，不要畫成多手多腳。

避免：

- 握筆寫字特寫。
- 數鈔票手指特寫。
- 精細烹飪刀工。
- 複雜握持與手掌姿勢。
- 大量正面笑臉。
- 逼真的臉部表情。

## 文化與職業辨識

- 使用環境、物件與色彩來辨識文化，不靠誇張五官或刻板服飾。
- 食物主題可用鍋具、攤位、盤子、桌椅、街區與食材。
- 歷史主題可用建築、地圖、交通工具與材料。
- 不把族群特徵卡通化。
- 不把所有人物畫成同一膚色或同一服裝；但變化要在 visual bible 內。

## 物件規則

- 每張圖只選 1 個主物件系統。
- 支援物件最多 8 類。
- 主物件可有組裝中的不同階段，形成 time-lapse。
- 小物件用簡化紙形，不追求產品寫實。
- 食物可較具體，但仍保持剪紙質地與自然色。

## 路徑

路徑不是正式流程箭頭：

- 彎曲的細線、虛線、腳印、街道、軌跡、繩索、紙帶。
- 一張圖最多 1 條主路徑與 2 條次路徑。
- 路徑要真的連接角色或物件。
- 不用整齊方框節點。
- 不在路徑旁生成文字。

## 人物一致性

同篇文章若有 recurring protagonist：

- 固定身形比例。
- 固定主色衣服。
- 固定頭髮／帽子輪廓。
- 固定臉部簡化方式。
- 固定紙片邊緣與陰影。
- 後續 prompt 明確寫 `the same recurring cutout character design as the article visual bible`。
