# Approved Style References

Place the three approved reference images in this directory using one of these extensions: `.png`, `.jpg`, or `.webp`.

```text
approved-featured.*
approved-mechanism.*
approved-comparison.*
```

- `approved-featured`: featured image, headline claim, winner/loser, burden, efficiency, or overview.
- `approved-mechanism`: gates, routing, write/keep/forget, filtering, transformation, or system mechanism.
- `approved-comparison`: scale, time, memory, cost, performance, burden growth, or result comparison.

The images are style references only. Never copy their exact composition, objects, labels, or article topic.

If these files are absent, the Skill continues with the compact Style Lock defined in `SKILL.md`.
